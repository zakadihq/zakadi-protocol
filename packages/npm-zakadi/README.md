# zakadi

Zakadi is an active face liveness check delivered as a short automated video call. This unscoped package holds the `zakadi` name on npm and ships the same shared protocol constants as `@zakadi/protocol` (session states, error codes, terminal states, close codes, challenge kinds, protocol version). The SDKs themselves are published under the `@zakadi` scope: `@zakadi/web-core`, `@zakadi/react`, `@zakadi/angular`, `@zakadi/react-native`, `@zakadi/protocol`, `@zakadi/node`.

Status: pre-release. Links: https://zakadi.dev (documentation), https://github.com/zakadihq/zakadi-protocol (source).
